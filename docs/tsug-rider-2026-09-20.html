Locked-rider recovery query (for Agent 5)

SELECT id, email, first_name, last_name, rider_status, is_active
FROM profiles
WHERE role = 'rider'
  AND is_active = false
  AND rider_status NOT IN ('pending_approval', 'rejected', 'resigned');
-- These riders were locked out by the old toggle code and need is_active set back to true.
